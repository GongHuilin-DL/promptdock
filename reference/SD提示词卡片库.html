① 提示词结构速览与语法小抄（建议先读）

通用结构：主体 subject + 动作/细节 detail + 环境 environment + 光线 lighting + 镜头 camera + 风格 style + 画质 quality。越靠前的词权重越高；逗号分段比长句更利于 SD1.5 解析。

语法写法作用
加权 / 降权(word:1.3) / (word:0.7)>1 加强，<1 压低；1.2~1.4 最稳
简写加权(word) ≈1.1 · ((word)) ≈1.21 · [word] ≈0.9括号叠乘，方括号递减
分步混合(A:B:0.6)到第 60% 采样步从 A 切到 B
分步替换[from:to:0.5]前 50% 步画 from，之后画 to
交替词[A|B]按采样步轮流生效，得到混合质感
合成 / 分段A:1 AND B:1.2 · … BREAK …独立条件流合成 / 强制换段编码
外部模型<lora:name:0.75> · embedding:xxx挂载 LoRA / Textual Inversion 触发词
风格混搭(styleA:1.1) + (styleB:0.6)主次分明的双风格
画质前缀(masterpiece, best quality:1.2)整组打包加权，可复用
镜头 / 画幅85mm, f/1.4 · 9:16配合输出分辨率控制景深与构图

模型差异：SD1.5 吃画质词与负面词；SDXL 对负面词依赖降低；FLUX / SD3 更偏好完整自然语言长句，权重语法可弱化。LoRA / Embedding 一般不能跨模型系列混用。
